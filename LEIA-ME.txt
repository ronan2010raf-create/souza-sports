SOUZA SPORTS — PUBLICAÇÃO PWA

O aplicativo está no arquivo index.html, com manifesto PWA, ícones e cache offline.

PUBLICAÇÃO GRATUITA NO GITHUB PAGES
1. Abra Settings > Pages neste repositório.
2. Em Build and deployment, escolha Deploy from a branch.
3. Selecione branch main e pasta /(root), depois clique em Save.
4. Aguarde o GitHub Pages concluir a publicação. O endereço do site será mostrado nessa mesma tela.
5. No Android, abra o endereço HTTPS no Chrome > menu ⋮ > Instalar app / Adicionar à tela inicial.

DADOS E BACKUP
Esta versão armazena os dados localmente no navegador do aparelho. A hospedagem
publica os arquivos, mas não sincroniza o estoque entre aparelhos.
Exporte o backup JSON regularmente e guarde cópias em locais seguros.
Limpar os dados do navegador ou trocar de aparelho pode apagar os dados locais.
Ainda não há login, banco remoto, criptografia própria ou backup automático.
Não compartilhe senhas, tokens ou chaves secretas.

PRIVACIDADE
O repositório é público e o site publicado no GitHub Pages também será público.
Não coloque informações pessoais de clientes, dados de pagamento ou outros dados
comerciais nos arquivos do repositório. Os registros de estoque do aplicativo
permanecem no armazenamento local do navegador deste aparelho.
